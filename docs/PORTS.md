# 开发端口登记（草案）

以下是避免四人本机联调冲突的建议分配，尚未创建服务、开放端口或部署网络。首次评审确认后实施。

| 模块 | 角色 | 建议开发端口 | 说明 |
| --- | --- | --- | --- |
| Banking Sandbox | B | 8000 | 银行工具 API，负责执行与真实模拟回执 |
| Agent API | A | 8001 | 计划、编排与前端交互入口 |
| Policy Engine | C | 8002 | 独立策略模块；是否单独进程由 A/B/C 评审确认 |
| Workbench | D | 5173 | React/TypeScript 开发服务器；生产入口由 D 决定 |

默认本机开发只绑定 `127.0.0.1`。容器内部可使用服务名通信，主机映射和是否暴露由 D 在部署 PR 中说明。SQLite 首版候选方案不需要数据库监听端口。

新增或变更端口，先走 [接口变更流程](INTERFACE_CHANGES.md)，同步用途、访问方和影响；不要临时占用其他模块的登记端口后只在个人代码中修改。
