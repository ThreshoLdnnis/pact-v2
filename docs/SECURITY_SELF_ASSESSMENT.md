# 0.4安全自评报告

基准日期2026-10-25。本地158项自动化测试通过，失败0；独立解压环境运行20组真实HTTP场景及重启恢复，独立sqlite3只读验收通过。所有数据合成，报告是MVP功能与攻击边界自评，不是银行合规认证或完整红队结论。准确证据见reports/tests.xml、context-http-smoke.json、sandbox-http-smoke.json、independent-deployment.json与mvp-acceptance.json。

## 资产、主体与边界

保护本人合成账户、资金承诺、任务、审批、规范回执及审计的完整性和归属。攻击输入包括自然语言、伪造候选、篡改步骤参数、旧审批、并发请求、上下文选择和返回丢失重试。模型和检索文本不属于授权主体，不能提交运行状态或银行回执。

所有变更和黄色查询必须经独立Policy等级判断与本人授权，银行在实际执行的同一SQLite写事务重查。沙箱管理员拥有破坏性合成测试控制，需独立令牌，默认关闭。数据库/宿主/部署管理员能修改源码及数据库，不在本沙箱抵抗范围内。

## 威胁与验证

| 攻击/故障 | 防护及实际验收 |
| --- | --- |
| 模型自行授权/伪造成功 | 封闭CandidatePlan，拒绝approved/status/risk等额外字段；权限由Policy判，成功由银行规范回执核验 |
| 模型不合规、拒答、超时、截断 | 外部兼容及Ollama候选验证，错误停住、不静默回退；未把供应商错误正文或密钥带到UI/审计 |
| 明确动作增加/遗漏 | 模型候选不能为查余额增付款，不能为转账只返回查询；账户不能被替换。仍需真实模型误解率评测 |
| 未确认读取订阅 | 黄色查询消费确认生成快照；直接查询无本人匹配回执403；取消需先有查询证据 |
| 越权资源和同名选择 | 每个资源校验本人；Bob跨读/跨选404；同名收款人本人选择后还需独立付款授权 |
| 拆单和旧等级 | 上海自然日用户累计、执行时重算，≤1000黄色、>1000红色；原黄色授权不覆盖红色 |
| 旧批准、改金额或改版本 | 审批10分钟且绑定主体/版本/步骤/动作/依赖/留存；暂停、修改、冲突、接管使旧批准失效 |
| 并发重复付款 | 固定步骤执行身份、幂等键与数据库唯一约束，BEGIN IMMEDIATE；并发重试仅一笔双边账务 |
| 原子性中途异常 | 后变更注入异常回滚余额、分录、审批消费和回执；故障单次绑定具体步骤，不进入Agent工具 |
| 多任务竞争资金 | 活动意图比较可用资金，冲突冻结变更和黄色查询，由用户选择；无FIFO；选择后不自动付款 |
| 保留与取消矛盾 | 本人明确保留意图持久化，新取消请求经相同冲突边界；旧执行入口也不可绕过 |
| 省略/含糊表达误执行 | 只用本人本会话/明确焦点；多个金额或目标要求版本绑定澄清；未知复合表达不部分执行 |
| 发送响应丢失 | 用户+request_id唯一，相同完整输入复用原响应，异参拒绝；UI保存待发送请求供原编号恢复 |
| 中断后伪造撤销 | 已付款、已取消保留事实；停止后续及依赖，未知先核验；仅支持撤销尚未付款定时承诺 |
| 交易结果未知时重付 | pending_verification冻结后续，只查原回执/分录，不重付或重规划；状态跨重启保留 |
| 人工接管绕过 | 冻结run/resume/execute/replan；交还仅记录说明和恢复检查，不允许手填成功或改账 |
| 审计/回执篡改 | 文档哈希、动作及分录绑定、审计链；独立oracle发现冲突窗口内执行、回执缺失等不变量破坏 |
| 未来资金被侵占 | 实时校验账户留存、计划留存取更高值及有效未来承诺；取消不释放已到期义务、不退款 |
| 注入与浏览器脚本 | 文本启发式拦截只是辅助；工具白名单、参数归属和授权兜底，React文本转义及CSP，无任意HTML |
| 超大请求、爆破和连续异常 | 32KiB请求限制，演示登录每IP失败限速，按用户3次执行异常触发60秒熔断 |

## 独立验证与部署证据

测试不只调用运行时verify函数：oracle用标准库sqlite3只读重建账户期初+分录、双边守恒、回执绑定、授权范围/等级、前置证据、冲突时间窗口与中断事实。篡改冲突结束时间的测试能识别窗口内执行，不依赖编排器自己的成功标记。数据库损坏或缺关键0.4表时报告失败，不自动修复。

Windows x64 CPython3.12离线包内19个wheel逐项SHA256锁定；新目录新venv，在PIP_NO_INDEX=1条件实际安装、HTTP执行和重启恢复。源码ZIP与清单逐文件校验；不包含.env、真实密钥、数据库、开发venv、node_modules或Git历史。离线包不包含Python解释器，其他平台在线安装仍需可信软件源。

运行依赖及前端锁文件未新增供应商SDK。reports/pip-audit.json与npm-audit.json沿用此前扫描（当次无已知漏洞），本轮未重新联网查询漏洞库；不把旧扫描称为当前安全保证。哈希锁定证明包与清单一致，不能证明上游包无恶意。
