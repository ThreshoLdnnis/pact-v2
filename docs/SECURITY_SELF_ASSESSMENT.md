# PACT V2.0 安全自评报告

评估日期：2026-10-24（Asia/Shanghai）。对象：0.1 MVP、本地合成数据沙箱。性质：开发者自测，不是第三方审计、合规认证或赛事官方安全结论。

## 结论与证据

已完成41个自动化测试，覆盖完整跨场景链路、权限边界、并发幂等、账务回滚、资金约束变化、暂停恢复、重规划、定时转账和输入/身份攻击。真实 HTTP 烟测核验账单分析、取消订阅和500元模拟转账，余额差额与双边分录一致。浏览器手工完成1001元模拟强验证并查询了银行回执。

证据：reports/tests.xml、reports/http-smoke.json、reports/pip-audit.json、reports/npm-audit.json、reports/screenshots/。首次41项测试用时约4秒，属于本机功能测试，不是并发容量或模型表现基准。

Python运行依赖和前端依赖扫描均未发现当次数据库中已知漏洞。该结果不包含未知漏洞、业务逻辑漏洞、供应链完整性认证，也不代表未来版本安全。

## 威胁、措施与验证

| 风险 | 实现控制 | 证据/限制 |
| --- | --- | --- |
| 模型越权授权 | CandidatePlan封闭字段，拒绝risk/status/approved；独立Policy决定等级 | 伪造风险/approved字段测试拒绝 |
| 未确认直接付款 | Banking根据已保存计划与服务端审批校验，缺授权只返回待审批 | 无审批余额不变，直接工具调用不能绕过 |
| 拆单跨阈值 | 用户所有账户上海自然日成功转出累计，执行时持写锁重算 | 600+400+0.01元边界及两笔预批准并发测试 |
| 红级降级/重放 | 审批绑定用户/版本/步骤/动作哈希，10分钟过期，消费一次 | 1000元包含边界、1000.01红级、旧版本和已消费审批拒绝 |
| 伪造强验证 | 独立模拟挑战2分钟有效，哈希保存，3次错误拒绝，按审批绑定 | 已测未申请/错审批码拒绝；流程明确为模拟，不是真实MFA |
| 并发重复扣款 | BEGIN IMMEDIATE、固定幂等键及两套唯一约束 | 8个并发重复请求仅一组分录和一笔付款 |
| 原子性失败 | 余额、两条分录、审批消费与回执同事务 | 写入后注入异常，所有变更回滚 |
| 审批后余额/承诺变化 | 执行时重新计算最低留存及有效承诺 | 审批后提高留存约束，付款失败且不扣款 |
| 侵占未来支出 | 未来账单/下一次订阅/定时转账预留 | 取消订阅释放9800分，超可用1分拒绝 |
| 定时登记冒充付款 | scheduled回执paid=false，到期新任务新授权 | 到期准备幂等，未授权不扣款，最低留存跨期保留 |
| 失败后重放已完成动作 | 新版本保留成功步骤与已核验回执，旧审批失效 | 重规划复用账单/取消步骤，只重做新付款 |
| 越权读取账户/回执 | Bearer会话、每个资源校验user_id，不区分不存在与他人资源 | Bob访问Alice账户/计划/回执均404，登出失效 |
| 提示/参数注入 | 规则入口启发式拦截、有限工具Schema、资源归属和最终授权边界 | 恶意文本、shell工具、浮点金额、DAG循环/未知依赖拒绝；启发式不保证识别全部注入 |
| 超大请求/登录爆破 | 32KiB含分块请求上限，登录每IP每分钟5次失败限制 | 大请求和分块请求413，登录第6次429；多进程限速非分布式 |
| 持续执行异常 | 3次异常后60秒按用户熔断；直接只读API仍可检查 | 3次约束失败后执行429 |
| 伪造回执/审计变化 | 后端查询动作绑定、文档哈希、交易双边分录，审计前向哈希链 | 篡改金额或审计事件检测失败；DB管理员可重算链，无外部防篡改保证 |
| 浏览器脚本注入 | React文本转义，工作台CSP、无任意HTML渲染、无外部脚本 | 已人工检查页面与真实回执展示；API文档单独允许Swagger CDN |

## 关键剩余风险

1. 演示登录共用已知PIN，可主动切换Alice/Bob；它不能代表真实客户身份隔离强度。真实系统需要独立用户认证、真正MFA、会话撤销和异常登录控制。
2. 模拟挑战码直接在演示UI展示，不能证明持有独立认证因子，不可宣传为银行级强认证。
3. 规则解析只覆盖有限语法，条件/否定/模糊金额会要求澄清；Ollama适配仅做过拒绝不合规输出测试，未完成真实模型连测与误操作率评估。
4. 审计链保存在同一SQLite，无外部锚点、WORM存储或独立签名。数据库/宿主管理员不在本沙箱防护边界内。
5. 统一进程、SQLite写锁、同步编排适合小规模演示。尚未完成负载测试、故障恢复演练、分布式授权、服务间认证、跨版本迁移和真实银行回执对接。
6. 订阅只模拟取消及下一次承诺释放，不接商户，不自动展开无限周期扣款。挂失、收款人新增和真实资金接口不在首版工具白名单。
7. 依赖版本已锁定，但未逐包锁定发行物哈希。安装和镜像构建需要可信网络与软件源，CI/依赖漏洞库的查询结果有时间边界。
8. 本机无Docker。[CI运行40069404218](https://github.com/ThreshoLdnnis/pact-v2/actions/runs/40069404218) 的test-and-build与docker-smoke均成功，覆盖镜像构建、Compose启动和真实HTTP烟测。这是CI环境证据，不等于本机Docker安装或生产容器验收。见reports/ci-verification.json。
