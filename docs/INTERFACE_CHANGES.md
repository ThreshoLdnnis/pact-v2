# 共享接口与端口变更流程

适用对象：公共 HTTP API、Banking Tool API、共享数据 Schema、审批/回执协议、错误码、事件字段，以及新增或变更监听端口。**新增、修改、废弃都必须先沟通再修改。**

1. 提交“公共接口或端口变更”Issue，填写原因、变更前后、受影响模块和兼容策略。
2. 在团队群同步下面的模板，附 Issue 链接；不得由工具代替成员声称已发群。
3. 等待受影响负责人明确回复；安全/授权/账务交界必须 B/C 参与。首次共享协议评审请 A/B/C/D 都参与。
4. 在协议 PR 中记录回复证据、更新文档与示例。先合并兼容性契约变更，再按依赖合并实现。
5. 废弃项写明过渡期与替代方案，清理调用方后再删除。

群里没有可引用链接时，记录时间、同步原文和负责人回复摘要。PR 作者对记录真实性负责；本仓库模板不会自动向群发消息，也不能自动证明团队已沟通。

## 可复制的群同步模板

```text
【PACT 公共接口/端口变更】新增 / 修改 / 废弃
负责人/角色：
用途与原因：
HTTP 方法 + 路径：
监听端口 / 服务间访问方式（如涉及）：
请求参数（字段、类型、必填、示例）：
响应（成功、错误码、示例）：
权限 / 审批 / 幂等影响：
影响模块与需要回复的负责人：
兼容/迁移方案：
Issue / 协议 PR / 文档链接：
期望确认时间：
```
